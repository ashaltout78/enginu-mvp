# Enginu — منصة تقييم المهندسين

MVP عربي لمنصة تربط مهندسي الميكانيكا بخبراء لإجراء مقابلات تقنية منظمة، وإصدار **تقييم مهني من المنصة** وملف عام قابل للتحقق. لا يقدّم المشروع شهادة Autodesk ولا يدّعي اعتمادًا منها.

## ما هو موجود الآن

- Landing page وتحويلات واضحة للحجز.
- واجهات Engineer / Expert / Admin قابلة للنقر.
- نموذج حجز لمسارات HVAC & MEP وMechanical Design وManufacturing وPower & Piping.
- Scorecard موحد: المعرفة التقنية، حل المشكلات، المهارات البرمجية، الحكم الهندسي، والتواصل.
- Public verified profile مع إخلاء مسؤولية اعتماد واضح.
- نموذج بيانات Supabase جاهز في `supabase/schema.sql`، وقابل لإضافة company portal عبر دور `company`.

## البنية المقترحة المجانية

هذه النسخة Static MVP مستضافة مجانًا عبر Sites. لنسخة الإنتاج استخدم:

1. **Supabase**: Auth، PostgreSQL، Row Level Security، Storage.
2. **Vercel أو Cloudflare Pages**: إذا نُقلت الواجهة إلى Next.js لاحقًا.
3. **Jitsi Meet** كبداية مجانية لاجتماعات التقييم، أو مزود مدفوع عند الحاجة للتسجيلات.

## التشغيل محليًا

افتح `dist/index.html` في المتصفح. لا توجد حزم مطلوبة لهذه النسخة.

## ربط Supabase

1. أنشئ مشروع Supabase مجانيًا، ثم شغّل `supabase/schema.sql` داخل SQL Editor.
2. انسخ `.env.example` إلى `.env.local` وضع URL والمفتاح العام فقط.
3. عند تحويل الواجهة إلى Next.js، استخدم Supabase Auth واتبع RLS قبل فتح التسجيل العام.

## قبل الإطلاق الفعلي

- أضف سياسات RLS كاملة لكل دور، وسجل تدقيق لتعديل النتائج.
- ضع شروط استخدام وموافقة صريحة على نشر الملف العام.
- تحقق يدويًا من خبرات الخبراء، ولا تستخدم شعارات/أسماء Autodesk أو شهاداتها إلا بتفويض مكتوب.
- أضف بوابة دفع، وسياسة إلغاء، وإشعارات البريد/WhatsApp.
